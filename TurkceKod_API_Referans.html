Metin Fonksiyonları

String işlemleri için tüm fonksiyonlar

Temel İşlemler
Uzunluk
(metin)
Metin veya dizinin eleman sayısını döndürür.
Sayi
Parametreler
metinMetinUzunluğu ölçülecek metin
Sayi n = Uzunluk("Merhaba"); // 7
Sayi m = Uzunluk([1,2,3]); // 3
MetinKes
(metin, baslangic, uzunluk?)
Metnin belirli bir bölümünü keser ve döndürür.
Metin
Parametreler
metinMetinKaynak metin
baslangicSayiBaşlangıç indeksi (0'dan başlar)
uzunlukSayiKaç karakter alınacak isteğe bağlı
MetinKes("Merhaba", 0, 3); // "Mer"
MetinKes("Merhaba", 3);    // "haba"
MetinBol
(metin, ayirici)
Metni ayırıcıya göre böler, dizi döndürür.
Dizi
Dizi parcalar = MetinBol("a,b,c", ","); // ["a","b","c"]
MetinDegistir
(metin, aranan, yeni)
Metindeki bir ifadeyi başka bir ifadeyle değiştirir.
Metin
MetinDegistir("Merhaba Dünya", "Dünya", "Türkiye");
// "Merhaba Türkiye"
MetinIceriyorMu
(metin, aranan)
Metnin içinde aranan ifade var mı kontrol eder.
Mantiksal
MetinIceriyorMu("Merhaba", "rha"); // Dogru
MetinBirlestir
(dizi, ayirici?)
Dizi elemanlarını birleştirerek tek metin yapar.
Metin
MetinBirlestir(["a","b","c"], "-"); // "a-b-c"
BuyukHarf / KucukHarf
(metin)
Tüm harfleri büyük veya küçük yapar.
Metin
BuyukHarf("merhaba"); // "MERHABA"
KucukHarf("MERHABA"); // "merhaba"
MetinIlkBuyuk("merhaba dünya"); // "Merhaba Dünya"
EslesVarMi / EslesBul / EslesTumBul
(metin, regex)
Regex eşleşme kontrolü ve sonuç döndürme.
Mantiksal / Metin / Dizi
EslesVarMi("test@mail.com", "^[^@]+@[^@]+\.[^@]+$"); // Dogru
EslesBul("abc123", "[0-9]+");    // "123"
EslesTumBul("a1 b2 c3", "[0-9]"); // ["1","2","3"]
EslesDegistir("a1b2", "[0-9]", "X"); // "aXbX"
MetinBaslangici / MetinSonu
(metin, aranan)
Metnin belirli bir ifadeyle başlayıp başlamadığını/bitip bitmediğini kontrol eder.
Mantiksal
MetinBaslangici("Merhaba", "Mer"); // Dogru
MetinSonu("Merhaba", "aba");       // Dogru
MetinIndeks
(metin, aranan)
Aranan ifadenin ilk bulunduğu indeksi döndürür. Bulunamazsa -1.
Sayi
MetinIndeks("Merhaba", "ha"); // 3
MetinTersCevir
(metin)
Metni tersine çevirir.
Metin
MetinTersCevir("Merhaba"); // "abahreM"

Veritabanı

İki ayrı sistem — online SQLite ve offline Türkçe SQL

⚠️ VTAc internet gerektirir (sql.js). İnternetsiz kullanım için VTOAc kullanın. Her iki sistemde de VTCalistir / VTSorgu / VTKaydet / VTKapat aynı şekilde çalışır.
Veritabanı Fonksiyonları
FonksiyonDönüşAçıklama
VTAc(isim)VTSQLite veritabanı açar (internet şart). IndexedDB'ye otomatik kaydeder.
VTOAc(isim)VTOffline VT açar (internet gerekmez). Türkçe SQL destekler.
VTCalistir(db, sql, params?)MantiksalSQL komutunu çalıştırır. 3. parametre: güvenli params dizisi
VTSorgu(db, sql, params?)DiziSELECT sorgusu — her eleman bir satır nesnesi
VTKaydet(db, dosyaAdi?)MantiksalIndexedDB'ye kaydeder. dosyaAdi verilirse dosya indirir.
VTKapat(db)—Veritabanını kapatır ve otomatik kaydeder
Türkçe SQL (VTOAc)
TürkçeSQL Karşılığı

SIRALA / SINIR / ATLAORDER BY / LIMIT / OFFSET

Varyant db = VTOAc("rehber");

VTCalistir(db, "TABLO_OLUSTUR EGER_YOKSA kisiler (id SAYI BIRINCAL_ANAHTAR OTOMATIK_ARTAN, ad METIN, yas SAYI)");
